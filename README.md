# Telegram Barbershop Booking Bot

An asynchronous Telegram bot for booking barbershop services online. Written in Python using the Aiogram 3 library.

## Features
- User registration (collecting name and contact phone number).
- Browsing the service catalog via an inline menu.
- Selecting a convenient time slot for the appointment (09:00 – 20:00).
- Automatic administrator notification regarding new bookings.

## Tech Stack
- **Language:** Python 3.10+
- **Framework:** Aiogram 3.x
- **Environment Management:** python-dotenv
